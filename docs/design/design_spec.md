**规格优先级**：本文件文字 > SVG 示意图 > 旧文档。SVG 中坐标/字号为 @1x 示意，颜色为深色静态示意值，实现以 tokens.json 为准。

**术语约定**：「工作台 Tab」= L1 第二个导航项（导航概念）；「工作台页」= 它直达（或从项目列表 push 进入）的项目级页面（页面概念，导航标题 = 项目名）。两者同名是 iOS 惯例（Tab 名 = 落地页名）。本文件中「工作台」单独出现时，默认指工作台页；工作台页上不存在「工作台」字样，页面归属由 Tab 选中态表达。

**主题工作流（已与产品确认）**：新功能先做深色 → 产品确认结构 → 再同步浅色（浅色仅换 token 值，不换布局）。HTML 轨页面经 `data-theme` 运行时切换双主题（index 顶部开关 → iframe postMessage 联动），**不产出独立浅色 HTML 文件**；SVG 轨保留 `-light` 变体双文件，由 index 运行时换图。

## 1. 全局铁律（逐条可验收）

1. **深度封顶 ≤3 层**：L1 Tab → L2 工作台 push → L3 详情 push。工作台内部切换（实例/工具）不加导航深度。
2. **运行状态永不销毁**：切 Tab、push、开 sheet、断线，任何导航都不终止 Agent/Terminal 运行；重连后按缺口自动回放。恢复 = 续（同一会话），不是新建。
3. **核心组件单例、两种呈现**：文件浏览器（项目内=工作台工具 / 全局=Tab）、Git 检视（同）、技能管理（仅 L1 插件 Tab，作用域切换 全局⇄本项目）、历史（手机=sheet，平板/桌面=Sidebar 列表切换）、会话列表作用域（iPad/Mac：项目⇄全部 分段切换；项目=当前项目实例区，全部=按项目分组列表，见 05g）。数据层唯一：作用域只是查询参数（scope），不新增实体。
4. **Tab = 平级目的地**：项目 / 工作台 / 文件 / 插件 四 Tab 内不放内容展开；工作台内部切换走行 2，不走 push。
5. **三端同名同图标，只换容器**（映射表见 §6.1）；图标用 SF Symbols rounded 风格，禁止 emoji。
6. **工作台常驻 ≤3 行**（导航 / 实例+工具 / 运行摘要）；子 agent 条与审批托盘按需出现；低频操作进 ⋯。
7. **只读/运行边界**：文件与 Git 的"内容编辑、分支切换、合并、推送"是写操作，工具不提供——交给 Agent 或终端；文件工具允许**结构操作**（新建/重命名/移动/删除/上传，见 §5.4）。
8. **双主题**：所有屏幕深浅两态可渲染；颜色只经 tokens.json 语义名引用，禁止散落 HEX（验收机检项）。HTML 轨组件单源 `assets/components.css`——改一处全部页面生效，页面私有样式只放"仅本页出现"的选择器。
9. **设计语言遵循 Apple HIG**（§7.0）：系统控件优先、SF Symbols、Dynamic Type、系统手势。

## 3. L0 / L1 逐页规格

### 3.1 登录（06-login.html，L0 cover）
- 结构：品牌区（蓝色圆角方块内 terminal 图标 + 产品名 + 标语）→ 服务器地址行（可点改，mono）→ 密码框（secure）→ 登录主按钮 → 免登说明 → 底部语言入口 + PWA 提示。
- 交互：登录成功 → 签发 token → dismiss → 上次位置（默认工作台）。密码错误 = 输入框描红 + 行内提示。断网 = 按钮变「重试连接」。
- 状态：无 Tab Bar；双语跟随系统，底部可手动覆盖。

### 3.2 项目 Tab（02 深色 / 02x 浅色）
- 结构：Large Title「项目」+ ⚙/＋ → 搜索（项目与会话）→ **全局活动**卡（纵向，置顶优先，一行一会话：状态点 + 标题（单行截断）+ 摘要 + 项目 chip + 时间；底部「查看全部活动 ›」）→ **项目 · N** 列表（图标 + 名称 + 最近活动摘要 + live 徽标）。
- 交互：点项目 → push 工作台；点活动行 → 跨项目直达该会话；点置顶行同；＋ → 08 sheet；⚙ → 07 设置。
- 状态点语义（全局统一）：**绿 = 运行，橙 = 待审批，灰 = 空闲/结束**。
- 设计理由：项目 Tab 回答「哪里需要我」——活动摘要是决策信息，路径不是（路径在项目详情）。

### 3.3 工作台 Tab
- = 工作台页面的 Tab 直达形态：无 ‹ 返回键；恢复上次项目 + 上次实例 + 工具面板 + 输出流阅读位置。默认「跟随最新」，用户曾上翻则恢复阅读位并显示「↓ 实时」胶囊。

### 3.4 文件 Tab（10-tab-files-global.html）
- 与项目文件工具**同一组件**（铁律 3），作用域 = 服务器根目录。项目根目录行带 live 标与实例数；点项目文件夹 → 进入其工作台。其余能力（搜索/预览/结构管理/上传）同 §5.4。桌面/iPad：Sidebar「全局文件」→ 10-mac-files-global.html（同一组件，服务器根作用域，footnav 激活）。

### 3.5 插件 Tab（09-tab-plugins.html）
- 结构：作用域分段（全局 | 本项目·当前项目名 ▾）→ 搜索 → MCP 服务器组（连接状态 + 工具数 + 组头 ＋ 添加，点行进详情）→ 已安装技能组（卡片点入详情；「有更新」橙标）→ 市场推荐（安装）。桌面/iPad：Sidebar「插件」→ 09-mac-plugins.html（同结构）。
- **作用域规则**：「本项目」= 全局记忆的当前项目（与工作台标题 ▾ 同一份记忆，由切换器 03l 改变）；分段标签直接显示当前项目名，点段进入该项目作用域列表，段上 ▾ 打开切换器换项目；从未选项目时该段为空态引导「去工作台选择项目」。
- 深度页：**12 技能详情**（更新卡内确认变更 → 后台安装不打断会话；注入能力清单；卸载需确认并提示依赖链）；**13 MCP 详情**（状态/重启、命令与脱敏密钥、注入工具清单、注入范围、移除需确认）；**14 添加 MCP 表单**（stdio/SSE 字段联动、密钥存服务端脱敏、作用域、添加后自动连接并列工具）。
- **市场浏览**（17-market-browse.html，L3）：入口 = 市场「查看全部 ›」或点来源 chip（带来源过滤）；来源 chips + 类型 tab（全部/MCP/技能）+ 搜索；卡 = 名称 + 来源分级 + 简介 + 安装量 + [安装]。安装流：[安装] → 审计卡（16）→ 卡内进度 → ✓ 已安装并进已安装列表；点卡名称 → 详情（市场态按钮为「安装」）。管理源入口 = 详情页头部 ⚙（→ 15）。
- 规则：本项目作用域的技能/MCP 注入当前项目的 Agent 会话；项目工作台**不放**技能管理（已提升至本 Tab，去重声明）。

### 3.6 设置（07-settings.html，项目页 ⚙ push）；桌面/iPad：Sidebar「设置」→ 07-mac-settings.html（居中表单列，外观三态与主题开关同源）
- 分组：通用（外观：跟随系统/浅/深；语言）／RUNTIME 预设（Claude 模型预设、Pi Provider、Firecrawl Key，**脱敏**）／自动重试默认（次数、间隔指数退避、重发文案）／服务器（地址、连接状态、PWA 版本）／退出登录（红，确认；清 token 不清服务端数据）。
- 预设与重试默认 = 全局默认；会话 ℹ 面板可按会话覆盖（覆盖项在 ℹ 中标注）。

## 4. L2 工作台（核心，03–03z）

### 4.1 页面骨架（常驻 3 行，03）
1. **行1 导航**（44px）：‹ 项目（仅 push 态显示）｜项目名 ▾（可点 → 03l 项目切换 sheet；带上次项目记忆）｜ℹ ⋯
2. **行2 实例+工具**（30px）：`[内容头滚动区][＋ 新建][📁][⎇][📖]`——内容头随状态变（会话=实例 pills；文件=面包屑；Git=分支信息；Wiki=搜索框）；**三工具图标位置永不移动**，点击 = 原位高亮 + 下方内容替换（200ms 淡入），再点当前高亮图标返回会话。运行时清单（Claude/Codex/OMP/…）随插件扩展；运行摘要 chip 内容按运行时适配。
3. **行3 运行摘要**（24px，仅 Agent）：`✦ opus · plan · hi ▾`（点开 = 运行配置 Popover：模型/权限/effort/自动重试，与 ℹ 同数据）+ ⟳ 自动重试状态。Terminal → `tmux · dev ▾`；Chat → `pi · provider ▾`。
- 按需行：子 agent 概览条（绿 tint，点按跳转子 agent，仅并行子 agent 存在时）；审批托盘（橙 tint，仅待审批 > 0，位于输入区上方）。

### 4.2 实例状态机（pill 圆点 = 状态语言）
- **绿点 = 运行中**；**灰实点 = 空闲**；**红点 = 出错**；空心环 = 非激活实例。
- 用户中断不改 pill 颜色（流内一条分隔线）；错误态出现红色倒计时条（自动重试：取消/立即重试；配置在 ℹ）。
- 关闭会话（ℓ/ℓc 确认）→ 移出 pill 条 → 历史「已结束」→ 可恢复。**无归档功能**（已与产品确认）。
- 长按 pill（桌面右键）→ 02c 菜单：置顶/取消置顶 · 重命名 · 关闭会话…。置顶唯一作用 = 固定在项目 Tab 全局活动最顶部（紫色「置顶」标），建议 ≤5 条。
- 新建 = ＋（pill 尾常驻）→ 03j sheet（+Claude/+OMP/+Codex/终端/Chat；运行时清单随插件扩展，预设来自设置）。
- **审批中心**（11-approval-center.html，桌面 05f）：跨会话聚合所有待审批请求；卡 = 会话来源 + 项目归属 + mono 操作（强写操作红色高亮）；逐条 允许/拒绝、全部允许（二次确认）；点卡跳到会话位置；处理完自动通知对应会话继续。入口：全局活动橙色入口行（02）/ 工作台托盘标题 / 桌面状态栏「N 项待审批」/ iPad Sidebar 橙色行。
- **切换器**（03l，标题 ▾）：按项目分组的活跃会话列表；点会话 = 切项目并激活（一步）；点分组头 = 只切项目；搜索同匹配项目名与会话名；切换零销毁。

### 4.3 输出流（terminal-first）
- 用户任务 = 蓝 tint 卡（› 前缀）；助手文本 = 纯文本行；工具调用 = 卡片（图标 + mono 标题 + 状态/耗时/增删行数）；思考 = 收敛行（✦ 思考 · Ns，点开）；子 agent = 卡片（点头部展开，嵌套工具卡缩进一级，完成自动折叠）；回合尾 = 统计行（轮数/费用/token/耗时）+ 完成横幅（绿）或错误卡（红）。
- 输入区：运行中显示左侧红色停止键；空闲只有发送。断线时禁用。
- 长标题规则：所有会话名单行尾部截断，全名在 ℹ/历史；重命名建议 ≤8 字。

### 4.4 工具：Git（03m → 03t/03u/03r/03v）
- 行2 内容头 = `⎇ main ↑1↓0 · 工作区 N`；内容 = 工作区改动（M/A/?? 行）→ 点文件行 → **03r 单文件 diff（L3）**（基准跟随入口，⋯ 可切换）；最近提交；底部「全部历史 ›」「分支 (3) ›」。
- **03t 提交历史**：日期分组；行 = hash + 信息 + 作者（✦ = Agent 会话提交，标注来源会话）；上滑加载更早。点提交 → **03u 提交详情**：信息 + 来源标注 + 变更文件列表 → 点文件 → diff（基准 = 本次提交）。
- **03v 分支**：当前分支置顶 + ↑/↓ 统计；已合并置灰；点分支名 = 过滤该分支历史。只读边界橙框：切换/合并/推送交给 Agent 或终端。
- 桌面对齐：右栏「历史」分段点提交 → 详情在右栏展开；Git 无改动 → 空态「工作区干净」。

### 4.5 工具：文件（03o → 03x/03w/03y/03z → 03q）
- 行2 内容头 = 面包屑（点文件夹进入则同步推进）；内容 = 目录列表（文件夹在前、M 角标、时间）。
- **查**：行2 内容头变搜索框（03x，同 Wiki 样式）——项目内文件名子串过滤，结果显示相对路径。
- **预览**：点文件 → 03q（L3 顶部返回）：文本行号渲染/图片缩放；⋯ → 复制路径 / 在 Git 中查看 diff（跨工具互达）。
- **增**：⋯ → 新建（03y sheet：文件|文件夹 segmented + 名称 + 位置）；长按文件夹行 → 新建到此。创建空文件/文件夹，重名行内提示。
- **改/删**：长按文件行 → 03w 菜单：打开预览 / 重命名 / 移动到… / 删除…（红，确认；有未提交改动额外警示）。结构操作即时生效并同步 Git 工作区。
- **上传**（03z）：⋯ → 上传文件（系统选择器）；长按文件夹行 → 上传到此；桌面拖拽进右栏。队列行 = 进度条 + 速度 + 百分比 + 取消；同名冲突行内三选（覆盖/保留两者/取消）；失败可重试；>100MB 建议终端 rsync。
- 边界：**内容编辑不在工具内**（预览只读）——验收机检项。
- 目录记忆：重开 App 停留上次目录。桌面：右键 = 同款菜单，右栏树 + 搜索 + ＋（05e）。

### 4.6 工具：Wiki（03p → 03s）
- 行2 内容头 = 搜索（全文）；内容 = 页面树 + ✦ 徽标（可被引用）+ 引用来源标注。点页面 → 03s 阅读页（L3）：正文渲染 + 「让 Agent 读这篇」→ 选会话 → 注入上下文，会话流顶部出现引用卡（可移除）。v1 只读，编辑走源文件。

### 4.7 特殊状态
- **空态**（03h）：项目无实例 → 不渲染 pill 条，中央空态卡（主按钮新建 Agent）+ 项目工具仍可用；无任何项目 → 主按钮变「新建/采用项目」（08）。
- **断线**（03i）：导航上方橙横幅（自动重连指数退避 + 立即重试）；pill/摘要/托盘全部冻结变灰**不销毁**；输入禁用；重连按缺口回放。
- Chat/Pi（03g）：气泡式轻量对话；无审批/子 agent；长按 pill 置顶/重命名/关闭。
- 终端（03f）：无模型 chips；上滑看历史 + 「↓ 实时」回底；tmux 断线内容不丢；无审批托盘。

## 7. 设计语言与 Token

### 7.0 Apple HIG 基线
系统字体（SF Pro + 苹方）调系统 API，禁止捆绑字体；SF Symbols rounded；优先原生控件（Tab Bar/Nav/Segmented/Sheet/Context Menu），禁止自绘；材质毛玻璃（tokens HEX 为降级示意）；系统手势交给系统。

### 7.1 字阶 ↔ Text Style
tokens.typography：largeTitle 30/800 → Large Title；title 17/700 → Headline；body 16 → Body；callout 15；subhead 14；footnote 13；caption 12；micro 10.5 → Caption 2。Web 端用 rem（16px=1rem）等价 Dynamic Type。行高 UI 1.4；终端/代码 mono 栈。

### 7.3 双主题
tokens.json：`light.$value` + `$extensions["mode.dark"]`；语义名两态同名。深色基线：纯黑底 / #1C1C1E 卡 / #0A84FF 主蓝 / 语义色（success #30D158、warning #FF9F0A、danger #FF453A、pin #BF5AF2）；浅色：#F2F2F7 底 / #FFF 卡 / #007AFF 主蓝，文字色换深变体保对比（successText #28A745、warningText #E08600）。

**交付包运行时（HTML 轨）**：`assets/tokens.css` 是颜色的 CSS 映射（`:root` 深色 + `html[data-theme="light"]` 浅色覆盖）；`assets/components.css` 是跨页组件单源；`assets/theme.js` 提供主题切换（URL `?theme=` / localStorage / postMessage 三通道）。index 顶部「深色｜浅色」开关 → iframe 广播 + SVG 换 `-light` 变体图（无变体自动回退深色）。实现侧可把同一 `data-theme` 机制映射到原生两套 trait（iOS `overrideUserInterfaceStyle` / macOS `appearance`）。

### 7.4 图标映射
见 tokens.json `icon.mapping`（全部 SF Symbols rounded）。

### 7.5 多端字体
不捆绑字体；system-ui 栈按平台回退（Apple→SF Pro/苹方；Android→Roboto/思源黑体；Windows→Segoe UI/雅黑）；不加载 CJK webfont；验收比「布局层级一致」不比像素级字体一致。

## 8. 数据模型与实现要点

```
Project    { id, name, path, created_at, sort }
Instance   { id, project_id, type: agent|terminal|chat,
             name(别名,≤显示截断), runtime, model?, permission?, effort?,
             auto_retry{on,max,interval,text}, status: running|idle|error|closed,
             pinned, created_at, last_active_at }
Session    { id, instance_id, messages[], turns, cost_usd, tokens, replay_cursor }
Approval   { id, instance_id, payload, created_at, status: pending|approved|denied }
SubAgent   { id, parent_instance_id, name, status, tool_calls[] }
History    { instance_id, closed_at, last_summary }        # 关闭即写入，可恢复
McpServer  { id, scope: global|project, name, status, tools[], secret_ref }
Skill      { id, scope, name, desc, source, version, installed }
```

关键规则（可判真/假）：
1. 实例关闭 → status=closed + 写 History，pill 条即时移除；恢复 = status 复位 + 回放 replay_cursor 之后缺口，**不新建 Instance**。
2. 运行状态由服务端持有；客户端任何导航/断线不销毁；重连回放按消息序号补缺口。
3. 置顶 = Instance.pinned，驱动项目 Tab 全局活动排序（置顶组最顶），上限建议 5。
4. 全局活动行 = 跨项目聚合最近活跃实例（运行中优先，含待审批橙点）。
5. 文件结构操作（新建/重命名/移动/删除/上传）→ 文件系统 + 刷新 Git 状态；内容编辑 API 不存在于工具层。
6. 自动重试触发条件：API 错误；倒计时可取消；重发携带用户在倒计时期间的插话。
7. 边界：路径非法/重名 = 行内提示；上传同名 = 覆盖/保留两者/取消；实例名 >8 字仅截断显示不拦截；旋转/折叠保持恢复字段（项目、实例、工具分段、滚动位）。
