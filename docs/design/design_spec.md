## 1. 全局铁律（逐条可验收）

1. **深度封顶 ≤3 层**：L1 Tab → L2 工作台 push → L3 详情 push。工作台内部切换（实例/工具）不加导航深度。
2. **运行状态永不销毁**：切 Tab、push、开 sheet、断线，任何导航都不终止 Agent/Terminal 运行；重连后按缺口自动回放。恢复 = 续（同一会话），不是新建。
3. **核心组件单例、两种呈现**：文件浏览器（项目内=工作台工具 / 全局=Tab）、Git 检视（同）、技能管理（仅 L1 插件 Tab，作用域切换 全局⇄本项目）、历史（手机=sheet，平板/桌面=Sidebar 列表切换）、会话列表作用域（iPad/Mac：项目⇄全部 分段切换；项目=当前项目实例区，全部=按项目分组列表，见 05g）。数据层唯一：作用域只是查询参数（scope），不新增实体。
4. **Tab = 平级目的地**：项目 / 文件 / 插件 三 Tab（v1.5 终案——工作台 Tab 退役，项目 Tab = 会话的家）内不放内容展开；会话内切换走行 2，不走 push。
5. **三端同名同图标，只换容器**（映射表见 §6.1）；图标用 SF Symbols rounded 风格，禁止 emoji。
6. **工作台常驻 1 行**（导航；v1.5 单会话化——实例切换/新建/恢复收标题 ▾，面板入口迁行1，行2 退役）；子 agent 条与审批托盘按需出现；低频操作进 ⋯。
7. **只读/运行边界**：文件与 Git 的"内容编辑、分支切换、合并、推送"是写操作，工具不提供——交给 Agent 或终端；文件工具允许**结构操作**（新建/重命名/移动/删除/上传，见 §5.4）。

9. **设计语言遵循 Apple HIG**（§7.0）：系统控件优先、SF Symbols、Dynamic Type、系统手势。

## 3. L0 / L1 逐页规格

### 3.1 登录（06-login.html，L0 cover）

### 3.2 项目 Tab（02 深色 / 02x 浅色）
- 结构：Large Title「项目」+ ⚙/＋ → 搜索（项目与会话）→ **全局活动**卡（纵向，置顶优先，一行一会话：状态点 + 标题（单行截断）+ 摘要 + 项目 chip + 时间；底部「查看全部活动 ›」）→ **项目 · N** 列表（图标 + 名称 + 最近活动摘要 + live 徽标）。

- **删除项目**（project-delete，v1.5 补缺——此前无任何删除入口）：**贴底 sheet 确认**（族B；信息从容 + checkbox 内嵌），影响清单四行：**关闭全部会话实例（运行中亦然）** / **会话历史将一并清除（不可再 resume——项目移除后无 resume 宿主）** / 移出全局活动与置顶记录 / ☐ **同时删除磁盘上的项目文件**（默认不勾 = 磁盘保留，路径缩进小字）。语义 = **移出工作台管理 + 所有会话实例真正关闭 + 历史清除 + 磁盘由用户勾选定夺**；主按钮文案随勾选升级：未勾「移出项目（保留文件）」/ 勾选「删除项目（含磁盘文件，不可恢复）」；取消/✕/点 dim 均默认安全；**无阻止规则**（sheet 确认即足够）。语义边界：删除 = 用户显式销毁，是铁律 2「运行状态永不销毁」的**唯一例外**（仅用户显式删除触发）；「关闭」非「删除」——关闭的实例可从会话历史 resume。
- **重命名规则**：不置灰不禁用——有活跃实例时点击先到影响提醒（关闭全部实例 + 历史保留归属更新），确认后进 03w2 预填输入；无实例直达输入。与删除的规则差：**删除替你关（销毁兜底），重命名提醒你关（保留性操作）**。
- 状态点语义（全局统一）：**绿 = 运行，橙 = 待审批，灰 = 空闲/结束**。
- 设计理由：项目 Tab 回答「哪里需要我」——活动摘要是决策信息，路径不是（路径在项目详情）。

### 4.3 输出流（terminal-first）
- 用户任务 = 蓝 tint 卡（› 前缀）；助手文本 = 纯文本行；工具调用 = 卡片（图标 + mono 标题 + 状态/耗时/增删行数）；思考 = 收敛行（✦ 思考 · Ns，点开）；子 agent = 卡片（点头部展开，嵌套工具卡缩进一级，完成自动折叠）；回合尾 = 统计行（轮数/费用/token/耗时）+ 完成横幅（绿）或错误卡（红）。

### 4.4 工具：Git（03m → 03m2/03m3/03t/03u/03r/03v）
- 行2 内容头 = `⎇ main ↑1↓0 · 工作区 N`；内容 = 工作区改动（M/A/?? 行）→ 点文件行 → **03r 单文件 diff（L3）**（基准跟随入口，⋯ 可切换）；最近提交；底部「全部历史 ›」「提交…（03m2）」「分支 (3) ›」。
- **03m2 提交操作 sheet**：变更勾选清单（M/A 默认勾选，?? 默认不勾——防密钥误提交）+ 提交信息必填 → 提交到当前分支；点文件名 → 03r 复核。完成后工作区清零、↑+1、03t 顶部出现新提交（✦ = Agent 提交）。
- **03m3 放弃改动确认**：变更行长按/右键 →「放弃更改」→ 居中 Alert（恢复 HEAD、不可撤销）；Agent 编辑冲突红色提示（条件出现）；?? 文件放弃 = 删除（03w4 警示）。
- **03t 提交历史**：日期分组；行 = hash + 信息 + 作者（✦ = Agent 会话提交，标注来源会话）；上滑加载更早。点提交 → **03u 提交详情**：信息 + 来源标注 + 变更文件列表 → 点文件 → diff（基准 = 本次提交）。
- **03v 分支**：当前分支置顶 + ↑/↓ 统计；已合并置灰；点分支名 = 过滤该分支历史。只读边界橙框：切换/合并/推送交给 Agent 或终端。
- 桌面对齐：右栏「历史」分段点提交 → 详情在右栏展开；Git 无改动 → 空态「工作区干净」；操作 sheet/Alert = 居中（04c 形制）。

### 4.5 工具：文件（03o → 03x/03w/03y/03z → 03q 系）
- **容器**：文件工具承载于检视面板（03o）——会话页行2 面板入口钮 → 面板滑入（iPhone = 全屏层，含自身导航栏、覆盖 tab bar；iPad/Mac = 右栏展开）；动态标签条 = **文件树 / Git / Wiki 三个结构标签** ＋ 新建标签（03ob2）——**预览标签已退役**：文件预览与 wiki 阅读是"内容"，按 §4.5 容器矩阵进中栏；检视器只承载"结构与操作"（树/Git 操作/目录），身份分工 = **检视器放结构与操作、中栏放内容**。关闭面板让位回归，标签与会话状态零销毁（铁律 2）。
- 文件树标签内容 = **地址栏**（根段 = 项目图标，固定宽不随项目名变长；其后为相对路径面包屑，点上级段 = 返回上层；**规格 v1.5 升格 = .crumb 大框 34px/13px/r10，与搜索框同大小递进**——小胶囊样式退役，components.css 单源一处生效全包 22 页）+ **收缩搜索钮** + 当前目录列表（文件夹在前、M 角标、时间）。
- **查**：搜索与「返回上层」互斥（返回由地址栏承担）——**仅根目录显示收缩搜索钮**，点按原位展开输入（03x = 展开/过滤态，✕ 收起）——项目内文件名子串过滤，结果显示相对路径。
- **导航**：点文件夹 → 进入下层；**返回上一层 = 地址栏点上级段**（路径面包屑，可连跳多级）；列表为纯条目、无特殊首行。检视器同构（单层列表、文件夹在前），**从根渲染的树形废弃**（层级过深会引发横向滚动，且与 iPhone 不一致）。
- **预览 = 一个内容组件、四种容器（容器矩阵，§4.5 核心）**：
  | 容器 | 表面 | 形态 | ‹ 返回 |
  |---|---|---|---|
  | **面板标签** | 工作台（iPhone） | 树点文件 → 检视面板内新增/激活预览标签（workspace-preview，doc.text 图标），**面板不退出**——连续点多个文件逐个浏览，✕ 逐个关回文件树，结构标签（文件树/Git/Wiki）平级切换仍在 | 无（标签即导航；‹ 工作台退出面板，状态零销毁） |
  | **中栏标签** | 工作台（iPad/Mac） | 中栏 tabstrip 新增/激活文件标签（04b/05h，IDE 模式：树在检视器、内容在中栏，中栏伸展 flex） | 无（标签即导航） |
  | **push** | 全局文件（iPhone） | 文件 Tab 点散文件行 → push L3（03q 家族 = 全局文件语境基准图；**预览态不显示 tab bar**——与工作台文件预览一致，tab bar 仅列表层可见） | ‹ 返回列表原位 |
  | **主区推入态** | 全局文件（Mac/iPad） | 10m2：主区原地推入（‹ 返回浏览原位）；**每容器 × 全部类型落图**——Mac 代码/-md/-image/-edit/-unsupported 五态、iPad 列表 + 代码态（ipad-files-global/-preview，其余类型态与 Mac 同构） | ‹ 返回 |
  - **全类型覆盖原则（硬约束）**：四种容器各自都是完整预览界面——**每容器 × 全类型（代码/MD·HTML/图片/未知二进制 + 编辑态）必须逐格落图**（面板标签 workspace-preview 系 5 态、中栏标签 iPad/Mac 各 5 态、push 5 态、主区推入态 Mac 5 态 + iPad 列表/代码）；「同构声明」仅用于跨端同骨架的剩余类型态（iPad 推入态非代码态），不得用于替代容器内缺类型。**推入态编辑 = 内联于推入区**（emeta 放弃/完成 + 明文 + aux，同中栏编辑机制；pencil 退役）。
  - **升级路径**：全局文件容器的 ⋯ 含「在工作台打开」（仅 Mac/iPad；iPhone push 无此项）→ 切该项目工作台并开中栏文件标签——大面积 UI 切换仅在用户显式要求时发生。
  - **作用域条件**：根作用域（全局文件）无 Git → ⋯ 无「查看 diff」、无 diff 基准语义；重命名/移动 = 纯文件系统操作。
  - 入口统一：检视面板树（03o）/ 搜索（03x）/ 文件长按菜单「打开预览」（03w/05e）/ 会话流内文件链接（03ab）→ iPhone 开面板预览标签、iPad/Mac 开中栏标签；会话流内 wiki 链接 → 中栏阅读（三端，03s——wiki 是目录→单页阅读，无文件树连续浏览诉求，故不随文件回面板）；iPhone 全局文件行点按 → push。
  - 文本行号渲染/图片缩放；⋯ → 复制内容 / 复制路径 / 查看 diff（跨工具互达，工作台作用域）。

## 7. 设计语言与 Token

### 7.0 Apple HIG 基线
系统字体（SF Pro + 苹方）调系统 API，禁止捆绑字体；SF Symbols rounded；优先原生控件（Tab Bar/Nav/Segmented/Sheet/Context Menu），禁止自绘；材质毛玻璃（tokens HEX 为降级示意）；系统手势交给系统。

### 7.1 字阶 ↔ Text Style
tokens.typography：largeTitle 30/800 → Large Title；title 17/700 → Headline；body 16 → Body；callout 15；subhead 14；footnote 13；caption 12；micro 10.5 → Caption 2。Web 端用 rem（16px=1rem）等价 Dynamic Type。行高 UI 1.4；终端/代码 mono 栈。

### 7.2 横向标签条 · 指针设备规范（v1.5 新增；适用：检视器 ptabs / 中栏 tabstrip / 附件 chips 行等所有横向滚动条）
- **滚轮映射**：指针悬停横向标签条时，滚轮纵向增量自动映射为横向滚动（deltaY → scrollLeft）——解决鼠标（无触摸/无滚轮横轴）无法滚动视野外标签的问题；
- **Shift+滚轮 / 触控板双指**：原生横向行为不变；触摸拖动惯性原生。
- **溢出可视提示**：可滚动方向边缘 **12px 渐隐遮罩**（内容被裁方向出现、滚到头即消失）——让「视野外还有标签」始终可感知，不依赖用户尝试滚动。
- **尾部控件可达**：滚动到最右时尾部控件（ptabs 的「＋」、tabstrip 的 ＋/分屏/编辑/⋯ 前的最后一个标签）完整可见、无遮挡。
- 实现注意：滚轮映射须 passive:false 阻止页面纵向联动；渐隐遮罩用 mask-image 实现、不占布局宽。

### 7.3 双主题
tokens.json：`light.$value` + `$extensions["mode.dark"]`；语义名两态同名。深色基线：纯黑底 / #1C1C1E 卡 / #0A84FF 主蓝 / 语义色（success #30D158、warning #FF9F0A、danger #FF453A、pin #BF5AF2）；浅色：#F2F2F7 底 / #FFF 卡 / #007AFF 主蓝，文字色换深变体保对比（successText #28A745、warningText #E08600）。

**交付包运行时（HTML 轨）**：`assets/tokens.css` 是颜色的 CSS 映射（`:root` 深色 + `html[data-theme="light"]` 浅色覆盖）；`assets/components.css` 是跨页组件单源；`assets/theme.js` 提供主题切换（URL `?theme=` / localStorage / postMessage 三通道）。index 顶部「深色｜浅色」开关 → iframe 广播 + SVG 换 `-light` 变体图（无变体自动回退深色）。实现侧可把同一 `data-theme` 机制映射到原生两套 trait（iOS `overrideUserInterfaceStyle` / macOS `appearance`）。

### 7.4 图标映射

## 8. 数据模型与实现要点

```
Project    { id, name, path, created_at, sort }   # 删除 = 移出管理（instances 全部 closed、置顶/活动记录清除；path 磁盘文件保留，可重新 adopt）
Instance   { id, project_id, type: agent|terminal|chat,
             name(别名,≤显示截断), runtime, model?, permission?, effort?,
             auto_retry{on,max,interval,text}, status: running|idle|error|closed,
             pinned, color_index?, created_at, last_active_at }   # color_index = 置顶时分配的色板位（1–8，最小未用索引）；取消置顶不清除（再置顶颜色不变，颜色记忆连续）
Session    { id, instance_id, messages[], attachments[], turns, cost_usd, tokens, replay_cursor }
Approval   { id, instance_id, payload, created_at, status: pending|approved|denied }
SubAgent   { id, parent_instance_id, name, status, tool_calls[] }
History    { instance_id, closed_at, last_summary }        # 关闭即写入，可恢复
McpServer  { id, scope: global|project, name, status, tools[], secret_ref }
Skill      { id, scope, name, desc, source, version, installed }
```

关键规则（可判真/假）：
1. 实例关闭 → status=closed + 写 History，活跃列表即时移除；**恢复 = resume 该会话的 agent 历史**（`--resume` 式：agent 上下文/transcript 连续延续），**身份承诺 = agent 会话连续性**——Instance 壳是实现细节（壳常驻存活；壳背后 agent 进程不存在时**首次交互自动 resume**，用户无感；恢复出的现场沿用原会话名）。**恢复 ≠ fork**：不产生第二个并行副本；同一会话历史不可同时被两个现场 resume（会话独占——恢复后条目自历史可选区转入活跃列表）。
2. 运行状态由服务端持有；客户端任何导航/断线不销毁；重连回放按消息序号补缺口。
3. 置顶 = Instance.pinned，驱动项目 Tab 全局活动排序（置顶组最顶），上限建议 5。
4. 全局活动行 = 跨项目聚合最近活跃实例（运行中优先，含待审批橙点）。
5. 文件结构操作（新建/重命名/移动/删除/上传）→ 文件系统 + 刷新 Git 状态；内容编辑 API 不存在于工具层。
6. 自动重试触发条件：API 错误；倒计时可取消；重发携带用户在倒计时期间的插话。
7. 边界：路径非法/重名 = 行内提示；上传同名 = 覆盖/保留两者/取消；实例名 >8 字仅截断显示不拦截；旋转/折叠保持恢复字段（项目、实例、工具分段、滚动位）。

## 11. 图集规范（index.html 布局与维护法规）

图集自身也是一个信息架构问题——页面原型有铁律，图集同样有。展示单元的本质 = **（功能域， 端， 状态/浮层）三元组**，HTML 文件只是载体。

- **N1 卡片形态三分律**：iPhone 页（.stage）= iframe `width:100%` + `figure.phone`；iPad 页（.stagepad）= `.fit` 1228×0.878；Mac 页（.stagewin）= `.fit` 1288×0.84；scale 由 fitScale() 按容器实际宽度运行时计算（上限 0.84）。`scripts/audit-gallery.mjs` 形态对齐 mismatch=0 为交付门槛——**形态迁移必须连宿主 figure class 一起改**（05l 教训）。**stage 内绝对定位右界规律**：`.stage` 390 宽含两侧 12px 黑边（`*{box-sizing:border-box}`）→ 内容宽仅 **366px**，`overflow:hidden` 在 x=366 硬裁剪——绝对定位 pin/浮球右界 ≤346（20px 元素），越界会被裁成月牙且大窗口渲染不可见。
- **N2 设备优先视图 = 图集 IA**：顶部「结构总览」（IA 图）常驻；之下三端**设备视图**（sticky tab：iPhone/iPad/Mac，默认 iPhone，**无「全部」档**——混端无阅读意义），每视图内分组按**该端自己的动线**排序（iPhone 8 组 / iPad 2 组 / Mac 7 组），组头 = 序号 + 标题 + 一句 flow；卡片归属按作用域准入，不凭感觉。预算：每视图分组 ≤8、单组卡 ≤16，超限先重新归属而非加长。
- **N3 跨端对照 = 切 tab 对照**：同一功能在三个视图中的组位置对应（工具/浮层/全局文件…），caption 标基准端与容器差异；不设混排的「多端区」。
- **N4 浮层卡必有三答**：从哪唤起（入口）、锚定什么（基页）、如何退场；caption 含「归属链」（例：03o ⑤ → 长按 pill）。
- **N5 标注三级不重复**：页内 pin 面板 = 操作细节；caption = 定位 + 入口 + 关键规则（≤2 行）；flow = 区级动线。同一信息只出现一层。
- **N6 主题全局联动不可破**：`?theme=` 可分享；筛选/灯箱/深链等新机制不得破坏 postMessage 主题广播。
- **N7 深链寻址**：每卡 `data-page` = 稳定 id；`?page=03q5` **自动切到所属设备视图** + 滚动定位 + 短暂高亮，评审可发链接指卡。
- **N8 manifest 单一事实源（校验式）**：`gallery.manifest.json`（v2）记录每卡 device/group 与各组页序；index 手写维护，交付前 `scripts/audit-gallery.mjs` 对账——视图齐全、卡片↔manifest **顺序一致**、零重复、形态对齐、device 与页面舞台类型一致、徽章计数 = manifest 计数、iframe src 全部存在、无「全部」残留。计数徽章永远从 manifest 派生，禁止手写数字。
- **N9 规模化策略**：状态矩阵 =「基准端全态 + 其他端差异卡」，不追求每态×每端全画；新功能先落基准端（新卡先进 iPhone 视图对应组），其他端只补容器差异卡。
- **N10 版式节奏**：iPhone 视图 = 双列 grid（密度感），iPad/Mac 视图 = 单列全宽卡（内容感，fitScale 按容器宽自适应）；区头层级 ≤2；间距/圆角走 4/8；caption 样式与主题同源。
- **定案 D1–D4**：D1 端视图 tab（sticky：iPhone/iPad/Mac，默认 iPhone + localStorage 记忆，纯 display 切换不做 SPA）；D2 manifest 校验式起步，跑稳后再议生成式；D3 浮层维持独立卡 + 归属链，不做截图合成；D4 灯箱（卡角 ⤢ → 全屏原始尺寸查看 + 图例并读 + Esc/点外关闭）。
