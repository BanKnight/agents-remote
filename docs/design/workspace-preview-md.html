agents-web 部署指南

部署前请确认 环境变量 已就绪，详见 配置说明。所有命令在仓库根目录执行。

  • 构建产物上传至 srv-01 的 /var/www
  • 部署窗口：02:00 – 04:00（UTC+8）
  • 失败自动重试 3 次（指数退避）
# 构建并部署 npm run build ./deploy.sh --retry
⚠ 强写操作（push --force）需在审批中心逐条确认。
