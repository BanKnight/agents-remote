# UI 重构 v2（基于 v1.3 设计包的全新 UI 层）

> 创建：2026-09-20。总纲：`docs/design/redesign-v2.md`（权威源声明 + 23 条决策日志 + 九铁律映射 + 现状锚点 + 里程碑状态）。

## 目标

基于已定稿的 v1.3 设计包（Apple HIG 风格，iPhone/iPad/Mac 三端 54 页原型）**全新重写 UI 层**：token 整套换代（Apple 系统色双主题）、IA 重排（移动 4 Tab + 桌面 Sidebar + 深度模型 ≤3）、缺口功能补齐（跨会话审批中心等）。

## 动机

- 用户人工 QA 结论：核心完成度高，剩余问题集中在 UI/UX polish；旧 v1 深色 Server Agent Console 设计语言整体替换为 Apple HIG 双主题体系。
- 产品方向 OPC 多 agent：审批中心、多端形态是编排操作面的基础。

## 成果定义

- M0–M10 里程碑全部完成（状态见总纲 §6），每里程碑 reviewer 审查 + 四门禁全绿。
- spec §9 验收清单逐项通过；新 e2e 全套绿；**用户总验证通过**（D20）。

## 约束

- 只读边界（结构操作归 UI、内容编辑归 Agent）；PROJECTS_ROOT 不逃逸。
- 运行状态永不销毁（功能视图切换零销毁会话）。
- 双主题全程成立；禁止散落 HEX（机检把关）。
- 期间不阻塞现有功能可用性：每里程碑独立可交付。
